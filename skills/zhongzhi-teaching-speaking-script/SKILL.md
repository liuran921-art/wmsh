# 中职说课逐字稿 Skill

## 输入
必须优先读取：
1. 最终版说课PPT
2. 最终版教学设计
3. 比赛规定时长
4. 用户的表达偏好

若PPT尚未最终确定，可以先生成“页级草稿稿”，但要明确它需要随PPT同步更新。

## 核心原则
说课不是朗读教案，也不是模拟课堂。
说课的重点是向评委解释“设计逻辑”。

每个重点环节都尽量回答：
- 学生原本有什么问题
- 为什么用这个任务
- 学生具体怎么做
- 教师提供什么支架
- 学生会形成什么成果
- 怎么评价
- 这一环节如何突破重难点

## 逐页对齐
逐字稿必须与PPT一一对应。
格式：
P01｜页面标题｜建议时长
逐字稿：
……
过渡：
……

禁止出现：
- 稿子在讲P08，而PPT已翻到P10
- PPT有关键图表，稿子完全不解释
- 稿子大量重复PPT文字

## 时间分配
先按比赛总时长建立时间预算。
原则：
- 开头简洁
- 学情、目标、策略不拖
- 教学实施占最大比例
- 重难点突破、评价闭环、创新必须留时间
- 结尾简洁有力

根据用户实际语速校准字数；没有语速数据时，不虚构精确值，而采用“页级时长 + 总字数区间”控制。

## 语言风格
- 自然、专业、有比赛感
- 多用因果关系：“基于……因此我……”
- 多用证据关系：“学生通过……形成……，由……评价”
- 少用空泛套话
- 避免连续堆概念
- 每30—60秒至少让评委听见一次明确的设计逻辑或证据

## 推荐表达结构
开场：
“各位评委老师好，我今天说课的内容是……”

分析：
“本课真正需要解决的，不是学生不知道……，而是……”

策略：
“基于这一学情，我没有按照知识点逐项讲解，而是……”

实施：
“第一步……学生先……；这一环节主要解决……”
“在这里我设置……脚手架，是因为学生容易……”

评价：
“我不是在任务结束后再评价，而是把评价嵌入任务过程……”

创新：
“这里的创新不在工具本身，而在于它解决了……”

结尾：
回扣课题、学生发展和职业能力。

## 必须提供的辅助信息
在逐字稿后可附：
- 总时长
- 页级时间表
- 必须背熟的关键句
- 可压缩段落
- 可能超时段落
- 现场忘词时的“锚点词”

## 最终检查
- 是否像人在说，而不是论文
- 是否解释“为什么”
- 是否突出学生学习
- 是否逐页对应
- 是否在时间内
- 是否把最重要的比赛亮点讲透
