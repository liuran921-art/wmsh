# 中职说课比赛总控 Skill

## 核心任务
把用户提供的比赛文件、教材、学情、已有教学设计、课程资源，转化为彼此一致的“比赛三件套”：
1. 教学设计；
2. 说课PPT；
3. 说课逐字稿；
并在最后执行模拟评委审查。

## 基本原则
- 先建立“唯一教学逻辑母稿”，再生成三项成果，禁止三份材料各写一套逻辑。
- 面向中职学生：少空泛理论，多真实任务、案例、操作、练习、反馈和迁移。
- 所有目标必须可观察、可训练、可评价。
- 所有重难点必须在教学活动中找到明确突破点，并在评价中找到证据。
- 信息化、AI、数字化工具只有在确实改善学习效果时才使用，禁止为了“创新”而堆工具。
- 比赛表达必须回答三个问题：为什么这样教、学生怎么学、凭什么证明学会了。
- 若用户已有明确的教学主线或步骤，优先保留并强化，不随意推翻。
- 不把课堂课件与说课PPT混为一谈。说课PPT面向评委，课堂课件面向学生。

## 工作流

### 第1阶段：读取并诊断
读取用户提供的比赛评分标准、教材、教案、课件、任务单、学情材料等。
输出内部诊断：
- 教学内容逻辑
- 学情痛点
- 目标合理性
- 重难点
- 任务链
- 评价闭环
- 职业教育特征
- 创新性
- 比赛表达风险

缺少材料时不要停住，基于已有信息先完成可确定部分，并清楚标记“待补证据”。

### 第2阶段：建立教学逻辑母稿
固定形成：
1. 课程/教材定位
2. 学情
3. 学习痛点
4. 教学目标
5. 教学重点与难点
6. 教学策略
7. 真实岗位或生活情境
8. 教学任务链
9. 课前—课中—课后
10. 教学评价
11. 重难点突破证据
12. 教学创新
13. 教学成效
14. 反思与改进

检查“目标—活动—评价”是否一一对应。

### 第3阶段：调用教学设计思路
按 zhongzhi-competition-teaching-design 的标准生成细颗粒度教学设计。
要求细到非任课教师根据文档也能基本完整实施。

### 第4阶段：调用说课PPT思路
按 zhongzhi-teaching-competition-presentation 的标准，把教学设计转换为“评委能快速看懂”的说课PPT。
PPT必须有清晰主线、关键证据、少字图示化表达。

### 第5阶段：调用逐字稿思路
按 zhongzhi-teaching-speaking-script 的标准，根据最终PPT逐页写稿。
逐页对齐，不允许稿子与PPT错位。

### 第6阶段：模拟评委审查
按 zhongzhi-teaching-mock-review 的标准审查三份材料。
发现不一致时优先修正“母稿”，再同步改三份材料。

## 三件套一致性硬检查
逐项建立映射：
- 教学目标 -> 教学任务 -> 学生活动 -> 学习成果 -> 评价证据
- 教学重点 -> 哪个环节强化 -> 如何练习 -> 如何评价
- 教学难点 -> 哪个支架突破 -> 如何反馈 -> 如何迁移
- 学情问题 -> 对应教学策略
- 创新点 -> 解决了什么真实问题 -> 有何证据
- PPT页 -> 逐字稿页 -> 教学设计对应章节

若任何一项无法映射，不得宣称“形成闭环”。

## 推荐最终输出
按用户需求输出以下一个或多个成果：
- 比赛教学设计
- 说课PPT页级大纲/成品PPT
- 说课逐字稿
- 教师课堂衔接话术
- 学生任务单
- 评价量规
- 模拟评委问题与参考回答
- 三件套一致性检查表

## 风格要求
- 职教味：突出真实任务、岗位情境、实践能力、职业素养。
- 比赛味：突出设计依据、问题解决、证据、创新与反思。
- 中职味：任务清楚、脚手架充分、练习密度高、语言易懂。
- 避免口号式“岗课赛证、产教融合、数字赋能”等表述；如使用，必须解释它在课堂中的具体落点。
